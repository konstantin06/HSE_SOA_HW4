# Платформа уведомлений онлайн-банка

В работе спроектирована централизованная платформа для транзакционных, сервисных и маркетинговых уведомлений. Она принимает события банковских сервисов, учитывает настройки клиента, выбирает канал доставки и сохраняет результат отправки.

Основная часть посвящена критичным сообщениям, например подтверждению перевода или уведомлению о списании. Если основной канал не подтвердил получение сообщения, платформа переходит на резервный. По умолчанию используются push, затем SMS и email. Для защиты от повторов предусмотрены постоянный идентификатор уведомления, учёт попыток и проверка подтверждений.

В RFC сформулированы требования, рассчитана ожидаемая нагрузка и разобраны архитектурные риски. Сравниваются два решения: Kafka с PostgreSQL и workflow в Temporal. Для каждого варианта приведены C4 Container и диаграммы последовательности обычной доставки и переключения каналов. Выбор решения объясняется надёжностью, сложностью реализации и стоимостью эксплуатации.

Основной документ находится в [notification_platform_rfc.pdf](notification_platform_rfc.pdf). Исходники PlantUML и изображения схем находятся в папке [diagrams](diagrams/).
